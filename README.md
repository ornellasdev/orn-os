# Orn OS 🚀

**Orn OS** é uma distribuição Linux voltada para alta performance em jogos, baseada no **Fedora Atomic (Kinoite)** com **KDE Plasma 6**.

## Recursos Principais
- **Base Imutável:** Sistema operacional isolado e à prova de falhas (via uBlue).
- **Gaming-Ready:** Drivers NVIDIA/AMD pré-configurados de fábrica.
- **Performance:** Kernel com GameMode, Gamescope e MangoHud nativos.
- **Interface:** KDE Plasma customizado em tom Roxo Neon.
